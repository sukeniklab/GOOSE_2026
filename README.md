# Live cell data and scripts associated with "Rational design of disordered proteins for sequence-to-function investigation"

## by Kara Hunter, Trevor Brandt, Karina Guadalupe, Kavindu C. Kolamunna, Jeff M. Lotthammer, Nora M. Shamoon, Jessica K. Niblo, Brooke Nicholson, Lea M. Day, Alec Martinez, Alex S. Holehouse, Shahar Sukenik, Ryan J. Emenecker.  


Directory structure:

* figures_main_text - Organized scripts used to create main text figure panels.
* figures_si - Organized scripts used to create SI
* figures_ed - Organized scripts used to create SD
* Data - Contains data, and scripts, used for figures. Figures_2-3-4 has FRET and nuclear localization data, Figures_5 has sequencing data.
* legacy - data for original preprint ([https://www.biorxiv.org/content/10.1101/2023.10.29.564547v2])
